## 📌 Domain Overview
This repository contains scalable UI design systems, interactive clickable prototypes, and accessibility audits evaluated against international web standards.

---

## 🚀 Projects & Deliverables

### 1. App UI Component Design System (Figma)
* **Tool:** Figma
* **Project Scope:** Created a reusable, production-ready atomic design library for web and mobile products.
* **Key Implementation:**
  * Defined scalable design tokens for typography scales, color palettes, and spacing grids.
  * Built auto-layout components with interactive states (default, hover, pressed, disabled).
  * Documented component usage guidelines for engineering handoff.

### 2. Interactive High-Fidelity Prototype (Figma)
* **Tool:** Figma
* **Project Scope:** Prototyped an intuitive, high-fidelity mobile food/product ordering experience.
* **Key Implementation:**
  * Designed modern, accessible mobile screen interfaces aligned with platform HIG and Material standards.
  * Linked screens with smooth micro-animations, bottom navigation tabs, and modal bottom sheets.
  * Prepared an interactive clickable prototype ready for user testing.

### 3. Accessibility & Speed Audit (AXE DevTools)
* **Tool:** AXE DevTools / Lighthouse
* **Project Scope:** Conducted a comprehensive web accessibility evaluation based on WCAG 2.1 Level AA guidelines.
* **Key Implementation:**
  * Audited DOM structures to identify color contrast issues, missing aria labels, and semantic flaws.
  * Verified screen reader compatibility and keyboard-only navigation.
  * Formulated a prioritized remediation scorecard for frontend developers.
